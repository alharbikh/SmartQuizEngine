# SmartQuiz Engine — MVP v0.2

محرك محلي لاستخراج النص من ملفات PDF وDOCX وإنشاء اختبارات إلكترونية منها.

## المزايا الحالية

- استخراج PDF النصي وDOCX محليًا.
- توليد أسئلة محلي عبر Ollama + Qwen3 8B بدون إرسال المستندات إلى خدمة سحابية.
- وضع احتياطي لتوليد الأسئلة بدون AI.
- حفظ رقم الصفحة والمقطع الداعم عندما يكون المصدر PDF.
- مراجعة بنك الأسئلة وتعديله وتصديره JSON.
- تشغيل الاختبار وتصحيحه داخل الواجهة.

## التشغيل على Windows

1. ثبّت Python 3.11 أو أحدث.
2. ثبّت Ollama.
3. نزّل النموذج المحلي مرة واحدة:

```powershell
ollama pull qwen3:8b
```

4. داخل مجلد المشروع:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
streamlit run app.py
```

بعد تنزيل النموذج، توليد الأسئلة نفسه يعمل محليًا ولا يحتاج إلى API خارجي.

## حدود النسخة الحالية

- ملفات PDF المصورة تحتاج OCR وسيضاف دعمها لاحقًا.
- DOCX لا يملك مفهوم صفحة ثابتًا مثل PDF.
- التحقق الدلالي المتقدم من كل إجابة مرحلة لاحقة.
